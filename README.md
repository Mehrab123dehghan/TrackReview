# TrackReview | ترک‌ریویو

نسخهٔ اولیهٔ دانشگاهی برای نمایش ایدهٔ بازارگاه بازخورد موسیقی. این پروژه با **React، Vite، JavaScript و CSS ساده** ساخته شده است.

## اجرای محلی

پیش‌نیاز: Node.js و npm نصب باشند.

```bash
npm install
npm run dev
```

نشانی محلی که Vite در ترمینال نشان می‌دهد در مرورگر باز کن.

برای ساخت نسخهٔ قابل‌انتشار و پیش‌نمایش آن:

```bash
npm run build
npm run preview
```

خروجی آمادهٔ میزبانی در پوشهٔ `dist/` قرار می‌گیرد. برای Vercel یا Netlify، فرمان ساخت `npm run build` و پوشهٔ خروجی `dist` است. برنامه از مسیرهای hash استفاده می‌کند و برای جابه‌جایی بین دو صفحه به تنظیم بازنویسی سمت سرور نیاز ندارد.

## قابلیت‌های Phase 1

- دو مقصد فارسی و راست‌چین: «محیط محصول» و «پروندهٔ تحلیلی».
- کارت متخصص‌های ساختگی با تخصص، سابقه، هزینهٔ اعتبار نمایشی، وضعیت پذیرش و نمونهٔ بازخورد.
- فیلتر بر اساس موضوع بازخورد و تخصص متخصص.
- فرم درخواست با بررسی نام هنرمند، نام ترک، موضوع و توضیح حداقل ۲۰ نویسه‌ای.
- ذخیرهٔ درخواست معتبر در LocalStorage، پیام تأیید، و نمایش فهرست درخواست‌های ذخیره‌شده.
- پروندهٔ تحلیلی شامل مسئله، جایگزین‌ها، مخاطب، ارزش، فعالیت‌های آنلاین و آفلاین، طبقه‌بندی و هشت پرسش ارزیابی ایده.

## مرزهای نسخهٔ نمایشی

- پروفایل‌ها، سابقه‌ها، قیمت اعتباری و نمونه‌های بازخورد دادهٔ ساختگی‌اند.
- اعتبار فقط یک عدد نمایشی است. سایت پول دریافت نمی‌کند و پرداخت یا تقسیم درآمد واقعی ندارد.
- ورود کاربر، اشتراک، بارگذاری یا پخش ترک، ارتباط با متخصص و تحویل بازخورد واقعی پیاده‌سازی نشده‌اند.
- درخواست‌ها فقط در فضای LocalStorage مرورگر فعلی ذخیره می‌شوند؛ پایگاه داده یا همگام‌سازی بین دستگاه‌ها وجود ندارد.
- هیچ مصاحبه، نظرسنجی یا پژوهش بازار در این پروژه گزارش نشده است. ادعاهای بازار در پروندهٔ تحلیلی به‌عنوان فرض معرفی شده‌اند.

## ساختار پوشه‌ها

```text
src/
  components/       کارت متخصص، فرم درخواست و فهرست درخواست‌ها
  data/             دسته‌ها و پروفایل‌های نمونه
  pages/            صفحهٔ محصول و پروندهٔ تحلیلی
  utils/            دسترسی ایمن به LocalStorage
  App.jsx           پوسته و ناوبری hash
  App.css           ظاهر صفحات و اجزا
  index.css         قواعد پایه، قلم و رنگ‌ها
```

## دادهٔ نمایشی مرورگر

کلید ذخیره‌سازی درخواست‌ها `trackreview.demo.requests.v1` است. برای پاک‌کردن درخواست‌های نمونه، کلید را از بخش Local Storage در ابزار توسعهٔ مرورگر حذف کن.
